# 定期回顾 2026-06-10 — 优化建议

## 问题：话题分布严重偏斜

10 条推荐中历史占 6 条（60%），用户画像历史权重 0.9 导致发现阶段搜索预算被高权重话题吸干。用户要求各领域均衡——目的是发现高质量视频，不是复读已有的偏好。

---

## 根因：三处放大偏斜

| 环节 | 问题 |
|------|------|
| 发现层 | 搜索预算全按 `taste.topics` 权重分配，历史 0.9 拿最多预算 |
| L1 打分 | UP 主权重加分 `up_w * 0.30` 太猛，热门话题 UP 主轻易碾压冷门方向 |
| 策展 | `enforce_diversity()` 约束不够，同一话题未设上限 |

---

## 改动方案

### 1. 发现层：双池策略（discovery.py）

搜索预算拆开：

```python
# 兴趣池（50%）：按画像权重分配，历史/哲学/影视各搜一些
# 探索池（50%）：轮换冷门分区 + 随机关键词 + 高播放低偏好话题
# 确保每个主话题至少 N 条候选进 L1
```

探索池关键词建议池：社会、经济、科技、思想史、文学、艺术、法学、心理学（不含鸡汤）、人类学。

### 2. L1 打分：降 UP 主权重加分（scoring.py `_calc_l1_score`）

```python
# 改前
score += up_w * 0.30
# 改后
score += up_w * 0.15
```

理由：UP 主加分基于历史偏好，会压制从探索池进来的新方向。

### 3. 策展：设话题上限（curator.py `enforce_diversity`）

10 条最终推荐中，同一话题不超过 3 条。如果某话题超限，保留最高分 3 条，其余替换为次高分其他话题。

### 4. 检查点：降低偏斜阈值（checkpoint.py `check_discovery`）

```python
# 改前
max_pct < 0.7  # 单一话题 >70% 才打 warning
# 改后
max_pct < 0.5  # 单一话题 >50% 就打 warning
```

## ✅ 优化实施日志（2026-06-11）

### 改动 1：发现层双池策略（discovery.py）

**实施**：在 `discover()` 的策略3（关键词搜索）和策略4（分区探索）之间插入探索池。

```python
# 策略 3b：探索池（冷门方向轮换，避免历史垄断）
cfg = get_config()
if cfg.explore_ratio > 0:
    explore_kw = getattr(cfg, 'explore_keywords', [])
    if explore_kw:
        import random
        sampled = random.sample(explore_kw, min(3, len(explore_kw)))
        for kw in sampled:
            results = search_videos(kw, page=1, page_size=15)
            add(results, cfg.max_per_strategy)
```

**配置**（config.py）：
- `explore_ratio: float = 0.3` — 探索池占比 30%（兴趣池 70%）
- `explore_keywords` — 9 个冷门方向：社会、经济、科技、思想史、文学、艺术、法学、心理学、人类学

**与建议差异**：50/50 → 70/30，后续定期回顾可视效果调整。

### 改动 3：策展话题上限（curator.py `curate`）

**实施**：在多样性 floor（至少 1 条/方向）之上增加 ceiling（最多 3 条/方向）。

```python
CEILING = get_config().topic_ceiling  # 默认 3

# 第二轮补满时，同话题超限的跳过
if topic_counts.get(topic, 0) >= CEILING:
    blocked = True  # 跳过该候选
```

**配置**（config.py）：
- `topic_ceiling: int = 3` — 同一话题最多推荐数
- `diversity_floor: int = 1` — 每个核心方向最少条数

10 条推荐中，历史最多 3 条，剩下 7 条必须分散到其他方向。
