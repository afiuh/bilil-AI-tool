## 核心偏好：三大内容方向

### 1. 历史权谋分析 🏛️

**关键词**：权谋/政治/博弈/制度/权力结构/历史规律/朝代兴衰

**偏好风格**：
- 渤海小吏式分析框架：用模型重读历史，反常识视角
- 因果链清晰：A → B → C 的制度传导逻辑
- 反直觉：打破教科书叙事，展现历史复杂博弈

**不偏好**：
- 单纯历史故事叙述（无分析框架）
- 戏说/演义类（缺少严肃论证）

### 2. 哲学思辨 📚

**关键词**：毛选/马克思主义/矛盾论/实践论/辩证法/唯物主义/阶级分析

**偏好风格**：
- 有明确方法论框架的哲学分析
- 能解释现实问题的理论工具
- 逻辑严密、层层递进的论证

**不偏好**：
- 泛泛的人生感悟/心灵鸡汤
- 无框架的"哲思散谈"

### 3. 影视深度解读 🎬

**关键词**：新三国/大明王朝1566/吐槽/深度解读/剧本分析/人物剖析

**偏好风格**：
- 吐槽新三国 297 集式的系统拆解
- 人物行为逻辑分析
- 与历史原著的对比考据

**不偏好**：
- 无深度的剧情复述
- 粉丝向吹捧（缺乏批判视角）

## 明确排除

### 内容类型硬过滤

- ❌ 纪录片
- ❌ 有声书
- ❌ 电视剧原片
- ❌ 儿童内容
- ❌ 催眠/助眠
- ❌ 高考应试向

### 风格红线

- ❌ 人生感悟/心灵鸡汤类（即使话题相关）
- ❌ 泛泛而谈无分析框架
- ❌ 纯娱乐/搞笑（无信息量）

## UP 主评判标准（按重要性排序）

1. **论证严谨性** > 趣味性
2. **框架原创性** > 叙事流畅度
3. **信息密度** > 视频时长
4. **批判力度** > 迎合情绪

**"深度"的定义**：不是知识量多少，而是有没有一套自己的解释模型。

## 量化画像维度

| 维度 | 值 | 说明 |
|------|-----|------|
| `min_duration` | 300s (5min) | 低于此直接丢弃 |
| `max_duration` | 10800s (180min) | 高于此直接丢弃 |
| `preferred_duration` | 1800s+ (30min+) | 长视频偏好 |
| `claim_density_min` | 0.5/千字 | 每千字至少 0.5 个可验证断言 |
| `criticism_tolerance` | `factual_only` | 只接受"基于事实的批判"，不接受情绪化吐槽 |
| `vague_intro_penalty` | 是 | 开篇模糊断言 → 立即降权 |

## 演化规则

### 画像维度可迭代

通过 conversation 级反馈，持续提取新维度：
- 上次对话提炼：`criticism_tolerance`, `claim_density_min`, `vague_intro_penalty`
- 下次可能出现：论证结构偏好、叙事节奏容忍度、视觉呈现要求等

### 权重动态调整

- 每看完并评价一个视频 → 更新对应话题权重 ±0.03
- auto 级拉黑 → 对应风格标签直接置零
- conversation 级新维度 → 经用户确认后加入画像

### 黑名单管理

```
CLI: python -m bili_tool.cli blacklist add <uid>
CLI: python -m bili_tool.cli blacklist list
```
